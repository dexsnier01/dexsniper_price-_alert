# Dexsniper Price Alert

A cryptocurrency price monitoring system that tracks market prices and sends automated alerts to Telegram when selected price targets are reached.

## Features

- Monitor cryptocurrency prices
- Set price targets
- Price above and below alerts
- Telegram notifications
- Monitor multiple cryptocurrencies
- Track 24-hour price changes

## Planned Technologies

- Python
- CoinGecko API
- Telegram Bot API

## Project Status

Development in progress.
